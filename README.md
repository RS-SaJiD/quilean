# Quilean 🧹

**A fast, smart & beautiful Python CLI tool** to organize, rename and clean your files.

### Features
- Smart file organization by type
- Bulk rename with custom pattern
- Junk & temp file cleaner
- Folder statistics
- Colorful & modern CLI
- Easy to install and use

### Installation

```bash
# From GitHub
pip install git+https://github.com/RS-SaJiD/quilean.git

# After install
quilean --help
```

### Commands 
- quilean organize [path] → Organizes files
- quilean rename [path] → Bulk rename
- quilean clean [path] → Deletes junk files
- quilean stats [path] → Shows folder information.
