# quilean 🧹

A fast, smart and easy-to-use Python CLI tool to organize, clean and manage your messy folders.

### Features
- Smart File Organizer (by type)
- Bulk Rename files
- Find and remove duplicate files
- Clean junk/temp files
- Folder statistics
- Undo last operation
- Beautiful CLI with progress bar

### Installation

```bash
pip install git+https://github.com/RS-SaJiD/quilean.git
```
